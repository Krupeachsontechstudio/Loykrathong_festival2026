# ลอยกระทงออนไลน์ LIVE — คู่มือใช้งาน

## ไฟล์
- `index.html` — ตัวเกม 3D (Three.js) เปิดด้วย Chrome/Edge หรือใส่ใน OBS ได้เลย ต้องต่ออินเทอร์เน็ตเพื่อโหลด Three.js และฟอนต์
- `connector.js` — ตัวกลางรับคอมเมนต์/ของขวัญจาก TikTok LIVE และ Facebook Page LIVE ส่งเข้าเกม

## 0. เล่นพร้อมกันแบบเรียลไทม์สำหรับทุกคน (ไม่ต้องมีบัญชี Claude)
เกมใช้ WebSocket ส่งตำแหน่งตัวละคร ชุดที่ใส่ และการลอยกระทงของทุกคนแบบสด ๆ ผ่าน `server.js`
1. ติดตั้ง Node.js 18+ แล้วในโฟลเดอร์นี้รัน `npm install` และ `npm start`
2. เปิด `http://localhost:3000` — คนในวง Wi-Fi เดียวกันเปิด `http://<IP เครื่องคุณ>:3000` ได้
3. ขึ้นเว็บจริงให้ทุกคนเข้าได้: อัปโหลดทั้งโฟลเดอร์ไปบริการที่รัน Node.js ได้ (เช่น Render, Railway, Fly.io) ตั้ง Start command เป็น `npm start` แล้วส่งลิงก์ https ของเว็บให้ผู้เล่น เกมจะต่อ `wss://` ของเว็บเดียวกันเอง
4. ถ้าวางไฟล์เกมไว้ที่อื่น ให้เปิดเกมพร้อม `?server=wss://ที่อยู่เซิร์ฟเวอร์` หรือใส่ในตั้งค่า > เซิร์ฟเวอร์เล่นพร้อมกัน
หมายเหตุ: ลิงก์บน claude.ai ต่อเซิร์ฟเวอร์ภายนอกไม่ได้ (ข้อจำกัดความปลอดภัยของหน้าเว็บ) จึงใช้ห้องของ Claude แทน ซึ่งเข้าได้เฉพาะคนที่ได้รับเชิญ
ยอดรวมกระทงนับเฉพาะคนที่ออนไลน์อยู่ ใครออกจากงานยอดของคนนั้นจะหายไปจากยอดรวม

## API สำหรับแอปอื่น (REST + OpenAPI)
เอกสารแบบกดทดลองได้: `https://เว็บของคุณ/docs` · สเปก OpenAPI: `/openapi.json`

อ่านข้อมูล (ไม่ต้องใช้รหัส)
- `GET /api/status` — คนออนไลน์ ยอดกระทง/โคม/อธิษฐาน/เช่าชุด (ยอดรวมทั้งงาน เก็บในไฟล์ data.json)
- `GET /api/players` — ผู้เล่นออนไลน์ ตำแหน่ง ชุดที่ใส่ ของที่ถือ
- `GET /api/wishes?limit=20` — คำอธิษฐานล่าสุด
- `GET /api/events` — ฟังเหตุการณ์สด (Server-Sent Events): join, leave, float, lantern, pray, dress, command, gift, fx

สั่งเกม (ต้องตั้ง `API_KEY` บนเซิร์ฟเวอร์ และส่ง header `X-API-Key`)
- `POST /api/command` `{"user":"น้องดาว","text":"ลอยกระทง ขอให้สอบผ่าน"}` — ตัวละครชื่อนี้เดินเข้างานทุกจอ
- `POST /api/gift` `{"user":"บอส","gift":"Rose","count":1}`
- `POST /api/fx` `{"fx":"fireworks"}` — fireworks / petals / goldrain / lanterns

ตัวอย่าง:
```
curl -X POST https://เว็บของคุณ/api/command -H "X-API-Key: รหัสของคุณ" -H "Content-Type: application/json" -d "{\"user\":\"น้องดาว\",\"text\":\"ลอยกระทง ขอให้สอบผ่าน\"}"
```
จำกัด 20 คำสั่งต่อ 10 วินาทีต่อเครื่อง หมายเหตุ: บน Render แบบฟรี ไฟล์ data.json จะหายเมื่อเซิร์ฟเวอร์รีสตาร์ต

## 1. ทดสอบในเครื่อง
1. ดับเบิลคลิก `index.html`
2. พิมพ์คำสั่งในแถบ DEMO ด้านล่าง หรือกดปุ่ม 1–4
3. กด `S` > ทดสอบ > "ผู้ชมทดสอบ 8 คน" เพื่อดูหลายตัวละครพร้อมกัน
ทุกอย่างที่มาจากโหมดทดสอบมีป้าย **DEMO** และไม่ถูกนับในสถิติจริง

## 2. คำสั่งในแชต
| พิมพ์ | ผลในเกม |
|---|---|
| `ลอยกระทง ขอให้…` หรือ `ขอให้…` หรือ `1` / `float krathong` | เดินไปท่าน้ำ ลอยกระทง แสดงคำอธิษฐาน |
| `ปล่อยโคม …` หรือ `2` | เดินไปลานโคม ปล่อยโคมลอย |
| `เที่ยวงาน` หรือ `3` | เดินชมร้านค้าและชิงช้าสวรรค์ |
| `อธิษฐาน …` หรือ `4` | ไหว้ขอพรที่ศาลา |

ระบบกันสแปม: ข้อความเดิมจากคนเดิมภายใน 20 วินาทีจะถูกข้าม และแต่ละคนมีตัวละครรอ/อยู่บนจอได้ไม่เกิน 2 ตัว

## 3. ใส่ใน OBS
1. Sources > `+` > **Browser**
2. ติ๊ก **Local file** แล้วเลือก `index.html`
3. Width `1920`, Height `1080`, ติ๊ก **Control audio via OBS** (ถ้าต้องการคุมเสียงจาก OBS)
4. ปรับแผง: คลิกขวาที่ Source > **Interact** แล้วกด `E` เพื่อลากแผง, `S` เปิดตั้งค่า, `H` ซ่อนปุ่มมุมขวาบน
5. ก่อนไลฟ์จริง แนะนำซ่อน "แถบพิมพ์ทดสอบ (DEMO)" ในตั้งค่า > แผงบนจอ

## 4. เชื่อม LIVE จริง
1. ติดตั้ง Node.js 18+ แล้วในโฟลเดอร์เดียวกับไฟล์ รัน `npm i ws tiktok-live-connector`
2. เริ่มไลฟ์ TikTok ก่อน แล้วรัน (PowerShell):
   ```
   $env:TIKTOK_USER="ชื่อบัญชีไม่มี@"
   node connector.js
   ```
3. Facebook (เฉพาะไลฟ์ของเพจ): เพิ่ม `$env:FB_LIVE_ID="..."` และ `$env:FB_TOKEN="Page Access Token"` ก่อนรัน
4. ในเกม กด `S` > การเชื่อมต่อ LIVE > ที่อยู่ `ws://localhost:8787` > **เชื่อมต่อ**
5. มุมซ้ายบนจะแสดงสถานะจริงของแต่ละแพลตฟอร์ม ป้ายกลางจอจะเปลี่ยนจาก "ทดสอบ" เป็น "LIVE" เมื่อต่อแพลตฟอร์มสำเร็จ

ข้อจำกัด: TikTok ไม่มี API ทางการสำหรับอ่านแชตไลฟ์ ไลบรารีที่ใช้เป็นของชุมชนและอาจหยุดทำงานได้ / Facebook อ่านคอมเมนต์ได้เฉพาะไลฟ์ของเพจที่มีสิทธิ์ และอาจไม่ส่งชื่อผู้คอมเมนต์ / การไลฟ์สองแพลตฟอร์มพร้อมกันต้องใช้เครื่องมือ multistream ที่บัญชีของคุณได้รับอนุญาต

## 5. ของขวัญ
ตั้งค่า > ของขวัญ → เอฟเฟกต์ เขียนบรรทัดละรายการ เช่น `Rose=petals`
เอฟเฟกต์: `petals` ดอกไม้โปรย, `fireworks` พลุ, `goldrain` ฝนทอง, `lanterns` โคมลอยหมู่, `krathong` กระทงทองพิเศษพร้อมชื่อผู้ส่ง
ชื่อของขวัญต้องตรงกับที่ TikTok ส่งมา (ดูได้จากหน้าจอ connector.js)

## 6. งานเทศกาลอัตโนมัติ
เมื่อไม่มีคนพิมพ์ ชาวบ้าน (NPC) จะเดินเที่ยว ลอยกระทง ปล่อยโคม และมีพลุเป็นระยะ NPC ไม่มีชื่อ ไม่แสดงคำอธิษฐาน และไม่ถูกนับเป็นผู้ชมหรือสถิติ
